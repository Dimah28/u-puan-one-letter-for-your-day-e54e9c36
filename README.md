A deterministic Python program (standard library only) that writes exactly one letter — **Z** — to `/output/entry.txt`. Entry for make.fun's "One Letter for Your Day" bounty ($5).

## The letter

**Z** — for *zombie*: a day lived on zero sleep, shuffling through it half-awake. The most vivid, funny and true day-word a single letter can carry, and the task's own example ("Z for zero sleep"). Z is also the sleep symbol itself (Zzz), so the letter pictures the day twice over: no sleep, and the sleep you never got. The initial fits the word exactly — zombie, zero, Zzz — no sharper initial exists.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

No network, no randomness, no clock: two runs write byte-identical output. The entry is exactly 1 UTF-8 character, inside the 1–1 gate.
